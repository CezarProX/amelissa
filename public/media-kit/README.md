# Media Kit Setup

## Instructions

To enable the Media Kit download functionality:

1. Download all files from the Google Drive folder:
   https://drive.google.com/drive/folders/1Sb-5WDo2Er8ximL-Bt6maTjGQr3mHfXq?usp=drive_link

2. Create a ZIP archive containing all the media kit files

3. Name the ZIP file: `amelissa-media-kit.zip`

4. Place the ZIP file in this directory (`public/media-kit/`)

5. The download button will automatically work once the file is in place

## File Structure

```
public/
  media-kit/
    amelissa-media-kit.zip  <- Place your ZIP file here
    README.md               <- This file
```

## Notes

- The ZIP file should contain all press photos, bio, logos, and other promotional materials
- Maximum recommended file size: 50MB for optimal download experience
- The download will start automatically when users click the "Download Media Kit" button
